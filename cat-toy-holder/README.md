# Cat Toy Holder

A wall-mounted panel for storing cat toy wands, with keyhole slots for hanging.

## What it is

A flat rectangular panel (232 × 230 × 41.3mm) with:
- **7 vertical, open-top channels** across the front, evenly spaced (33.14mm pitch), each ~29mm wide — wand toys drop in from the top and rest against the channel floor.
- **2 keyhole-style mount slots** on the front face (wide circular head tapering to a narrower shaft) for hanging on wall screws, with reinforced backing behind each keyhole for strength.
- **20mm radius rounded corners** on all four corners, one continuous treatment top-to-bottom.
- Shelled/ribbed internal construction (not solid) to keep material use reasonable while staying strong at the mounting points.

## Files

- `step/`, `stl/`, `3mf/` — exported models. **`v5` is the current version** (`cat-toy-holder-v5.*`); `v4` files are kept as the superseded prior revision (v4 built the wand slots as horizontal round through-holes, which was wrong — v5 corrects this to the proper vertical open-top channel design).
- `dot_pipeline/specs.md` — full design/measurement history, including the parametric rebuild process from the original hand-designed part.
- `parameters.md` — dimensional reference.

## Print notes

- Material: PLA or PLA+.
- Orientation: front face down on the bed — no supports needed (every feature is a vertical wall, vertical channel, or straight-in pocket).
- Fits comfortably on a 256×256×256mm bed.
